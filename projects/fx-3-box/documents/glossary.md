# Thuật ngữ

| Thuật ngữ | Nghĩa |
|-----------|-------|
| Hộp (box) | _Owner bổ sung định nghĩa theo cách kênh dùng_ |
| SL | Stop Loss — mức cắt lỗ |
| TP | Take Profit — mức chốt lời |
| R | Đơn vị rủi ro. 1R = khoảng cách entry → SL. Lãi +3R = lãi gấp 3 lần mức rủi ro ban đầu |
| RR | Tỷ lệ Reward:Risk dự kiến lúc vào lệnh |
